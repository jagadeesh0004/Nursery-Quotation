PRIORITY 1: RACE CONDITION FIX (MEDIUM SEVERITY)
─────────────────────────────────────────────────────────────────────────

Problem:
Two concurrent requests can receive the same quotation number

Current Flow (UNSAFE):
Thread A: SELECT MAX(sequence)=5
Thread B: SELECT MAX(sequence)=5  ← Same result!
Thread A: Calculate next=6, insert GG0006
Thread B: Calculate next=6, insert GG0006 ← COLLISION

Fix Option 1: Database Row Locking (RECOMMENDED)
─────────────────────────────────────────────────

File: QuotationRepository.java

Add method:
@Query("SELECT COALESCE(MAX(q.sequence), 0) FROM Quotation q " +
       "WHERE q.userId = :userId AND q.year = :year AND q.deletedAt IS NULL")
int findMaxSequenceForUserAndYearWithLock(UUID userId, int year);

Implementation detail:
- Use JPA @Lock(LockModeType.PESSIMISTIC_WRITE)
- Or use native query with FOR UPDATE

Recommended Code:
```java
@Query(value = "SELECT COALESCE(MAX(q.sequence), 0) " +
               "FROM quotations q " +
               "WHERE q.user_id = ?1 AND q.year = ?2 " +
               "AND q.deleted_at IS NULL " +
               "FOR UPDATE", nativeQuery = true)
int findMaxSequenceForUserAndYearLocked(UUID userId, int year);
```

In QuotationNumberingService.generate():
```java
public GeneratedNumber generate(UUID userId) {
    int currentYear = Year.now().getValue();

    NurseryProfile profile = profileRepository.findByUserId(userId)
        .orElseThrow(...);

    // Acquires lock on quotations rows for this user+year
    int baseSequence = quotationRepository.findMaxSequenceForUserAndYearLocked(userId, currentYear);
    String initials = profile.getInitials().toUpperCase();

    int nextSequence = baseSequence + 1;
    String number = String.format("%s%04d", initials, nextSequence);

    return new GeneratedNumber(number, currentYear, nextSequence);
}
```

PRIORITY 2: SOFT DELETION SEQUENCE COUNTING (MEDIUM SEVERITY)
─────────────────────────────────────────────────────────────

Problem:
findMaxSequenceForUserAndYear() includes soft-deleted quotations

Current:
SELECT COALESCE(MAX(q.sequence), 0) FROM quotations q
WHERE q.user_id = ? AND q.year = ?  ← No deleted_at filter

Fixed:
SELECT COALESCE(MAX(q.sequence), 0) FROM quotations q
WHERE q.user_id = ? AND q.year = ? AND q.deleted_at IS NULL

File: QuotationRepository.java

Change:
```java
// OLD
@Query("SELECT COALESCE(MAX(q.sequence), 0) FROM Quotation q " +
       "WHERE q.userId = :userId AND q.year = :year")
int findMaxSequenceForUserAndYear(UUID userId, int year);

// NEW
@Query("SELECT COALESCE(MAX(q.sequence), 0) FROM Quotation q " +
       "WHERE q.userId = :userId AND q.year = :year AND q.deletedAt IS NULL")
int findMaxSequenceForUserAndYear(UUID userId, int year);
```

Or use SQLRestriction:
- Already applied at class level (@SQLRestriction("deleted_at IS NULL"))
- But explicit filter is clearer and safer


PRIORITY 3: INITIALS VALIDATION (MEDIUM SEVERITY)
─────────────────────────────────────────────────

Problem:
No validation of initials length

File: QuotationNumberingService.java

Current (UNSAFE):
```java
String initials = profile.getInitials().toUpperCase();
String number = String.format("%s%04d", initials, nextSequence);
```

If initials = "ABCDEFGH" (8 chars):
Result: "ABCDEFGH0001" (12 chars, exceeds 8-char format)

Fixed:
```java
String initials = profile.getInitials().toUpperCase();

// Truncate to max 4 characters
if (initials.length() > 4) {
    initials = initials.substring(0, 4);
    log.warn("⚠️ Initials truncated to 4 chars: {}", initials);
}

String number = String.format("%s%04d", initials, nextSequence);

// Validate format
if (number.length() > 8) {
    throw new BusinessException("Generated number exceeds maximum length: " + number);
}
```

Also add to NurseryProfile entity validation:
```java
@Column(name = "initials", length = 4)
@NotNull
@Size(max = 4, message = "Initials must be max 4 characters")
private String initials;
```

```java
private void assignQuotationNumber(Quotation quotation, UUID userId) {
    if (quotation.getQuotationNumber() == null) {
        try {
            var generated = numberingService.generate(userId);
            quotation.setQuotationNumber(generated.quotationNumber());
            quotation.setYear(generated.year());
            quotation.setSequence(generated.sequence());
        } catch (BusinessException e) {
            // Log detailed error for debugging
            log.error("❌ Failed to assign quotation number for userId: {}", userId, e);
            throw new BusinessException(
                "Cannot finalize quotation: " + e.getMessage() +
                " Please ensure your profile is complete.");
        }
    }
}
```

```java
void testConcurrentGeneration() throws InterruptedException {
    ExecutorService executor = Executors.newFixedThreadPool(5);
    Set<String> numbers = Collections.synchronizedSet(new HashSet<>());

    for (int i = 0; i < 10; i++) {
        executor.submit(() -> {
            GeneratedNumber num = service.generate(userId);
            numbers.add(num.quotationNumber());
        });
    }

    executor.awaitTermination(5, TimeUnit.SECONDS);

    // All numbers should be unique
    assertThat(numbers).hasSize(10);
}
```

```java
@Slf4j
public class QuotationNumberingService {

    public GeneratedNumber generate(UUID userId) {
        log.info("🔢 [START] Generating quotation number for userId: {}", userId);
        long startTime = System.currentTimeMillis();

        try {
            int currentYear = Year.now().getValue();
            NurseryProfile profile = profileRepository.findByUserId(userId)
                .orElseThrow(() -> new BusinessException("Profile not found"));

            log.debug("📋 Profile found: initials={}", profile.getInitials());

            int baseSequence = quotationRepository.findMaxSequenceForUserAndYear(userId, currentYear);
            log.debug("📊 Max sequence for user in {}: {}", currentYear, baseSequence);

            String initials = profile.getInitials().toUpperCase();
            int attempts = 0;

            while (attempts < 5) {
                int nextSequence = baseSequence + 1 + attempts;
                String number = String.format("%s%04d", initials, nextSequence);

                if (!quotationRepository.existsByUserIdAndQuotationNumber(userId, number)) {
                    long duration = System.currentTimeMillis() - startTime;
                    log.info("✅ [SUCCESS] Number generated: {} (attempts: {}, duration: {}ms)",
                             number, attempts + 1, duration);
                    return new GeneratedNumber(number, currentYear, nextSequence);
                }

                log.debug("⏭️  Attempt {}: Number {} exists, retrying", attempts + 1, number);
                attempts++;
            }

            log.error("❌ [FAILED] Could not generate number after 5 attempts for userId: {}", userId);
            throw new BusinessException("Unable to generate unique quotation number");

        } catch (Exception e) {
            long duration = System.currentTimeMillis() - startTime;
            log.error("❌ [ERROR] Quotation number generation failed (duration: {}ms)", duration, e);
            throw e;
        }
    }
}
```

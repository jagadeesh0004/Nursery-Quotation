KEY FLOW:
1. User finalizes quotation
2. QuotationService.assignQuotationNumber() called
3. QuotationNumberingService.generate(userId) called
4. Gets max sequence from DB for user+year
5. Generates next number (INITIALS + SEQUENCE)
6. Checks uniqueness (per-user, not global)
7. Returns GeneratedNumber record
8. Quotation saved with number

CRITICAL QUERIES:
- findMaxSequenceForUserAndYear(userId, year)
  SELECT COALESCE(MAX(q.sequence), 0) FROM quotations q
  WHERE q.user_id = ? AND q.year = ?

- existsByUserIdAndQuotationNumber(userId, number)
  SELECT COUNT(q) > 0 FROM quotations q
  WHERE q.user_id = ? AND q.quotation_number = ?

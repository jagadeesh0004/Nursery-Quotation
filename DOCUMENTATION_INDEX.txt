SYSTEM ARCHITECTURE SUMMARY:
================================================================================

FORMAT: AAAABBBB
  AAAA = Nursery initials (first letter of each word, max 4)
  BBBB = Sequential number (4 digits: 0001, 0002, etc.)

Examples:
  "Go Green Nursery Ltd" → GGNL0001, GGNL0002, etc.

SCOPE: PER-USER (not global)
  Each user gets their own independent sequence
  Two users CAN have the same quotation number

DATABASE CONSTRAINTS:
  ✅ uk_user_quotation_number (user_id, quotation_number) UNIQUE
  ✅ uq_quotation_user_year_seq (user_id, year, sequence) UNIQUE

FILES INVOLVED:
  1. QuotationNumberingService.java - Core generation logic
  2. Quotation.java - JPA entity with constraints
  3. QuotationRepository.java - Database access layer
  4. QuotationService.java - Business logic orchestration
  5. QuotationController.java - REST endpoints
  6. V1__initial_schema.sql - Database schema
  7. V008__Fix_Quotation_Constraint.sql - Fixed constraint (global→per-user)

================================================================================
KEY EXECUTION FLOW:
================================================================================

Client Request → POST /api/quotations (with finalize=true)
          ↓
    QuotationController.create()
          ↓
    QuotationService.createQuotation()
          ↓
    Validate request (customer info, items)
          ↓
    Create Quotation object
          ↓
    Apply items and calculate totals
          ↓
    If finalizing: assignQuotationNumber()
          ↓
    QuotationNumberingService.generate(userId)
          ↓
    Get nursery profile (for initials)
          ↓
    Query: SELECT MAX(sequence) for user+year
          ↓
    Calculate next sequence number
          ↓
    Format number: initials + sequence
          ↓
    Check uniqueness (per-user)
          ↓
    If collision: Retry (up to 5 attempts)
          ↓
    Save quotation with number to database
          ↓
    Return response to client

Total steps: 16
Average time: ~50-100ms

================================================================================
TOP 3 FLAWS:
================================================================================

1. RACE CONDITION (Medium Severity)
   Concurrent requests can generate same number
   Fix: Add row-level database locking
   Effort: 2-3 hours

2. SOFT DELETION IN SEQUENCE (Medium Severity)
   Soft-deleted quotations counted in max sequence
   Fix: Add deleted_at IS NULL filter
   Effort: 1 hour

3. INITIALS VALIDATION MISSING (Medium Severity)
   No validation of initials length (max 4 chars)
   Fix: Add truncation and validation logic
   Effort: 1 hour

See QUOTATION_NUMBER_SYSTEM_ANALYSIS.txt (Section 4) for all 10 flaws.
